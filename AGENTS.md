# Repository Working Rules

## Git commits

- Write concise, natural commit messages that describe the actual change.
- Do not add `Co-authored-by` trailers to commits.
- Do not mention ChatGPT, Codex, OpenAI, AI generation, or AI assistance in commit messages or trailers.
- Review the staged diff before every commit and include only intended project files.

## Code comments

- Write comments in natural, professional language only when they explain intent, a business rule, or a non-obvious technical decision.
- Avoid comments that merely repeat what the code already says.
- Do not add comments that mention ChatGPT, Codex, OpenAI, or generated code.
